# Evaluation Artifacts

Generated by `src/evaluate.py` and `src/predict.py`, never edited by hand.

The files currently checked in come from a pipeline smoke test: `yolov8n` trained for 5 epochs on COCO128 (a tiny, public, 128 image, 80 generic-object class sample) using `scripts/download_dataset.py --source sample`. This validates that download, prepare, train, evaluate, export and predict all work correctly end to end. It is not a measure of PPE detection accuracy.

To produce the real safety detection metrics for the ten PPE classes, follow "Reproducing the full pipeline" in [../README.md](../README.md) with `--source roboflow`, then re-run:

```
python src/evaluate.py --weights runs/visionops_ppe/weights/best.pt
python src/predict.py --weights runs/visionops_ppe/weights/best.pt --source <sample images> --out reports/sample_predictions --gif
```

This overwrites `metrics.json`, `metrics.md`, `confusion_matrix.png`, `pr_curve.png` and `sample_predictions/` with results from the real dataset.

| File | Description |
|---|---|
| `metrics.json` | Overall and per class precision, recall and mAP@0.5, machine readable. |
| `metrics.md` | Same data as a Markdown table, embedded in the root README. |
| `confusion_matrix.png` | Normalized confusion matrix over the validation split. |
| `pr_curve.png` | Precision-recall curve over the validation split. |
| `sample_predictions/` | Annotated sample images and a `demo.gif` assembled from them. |
